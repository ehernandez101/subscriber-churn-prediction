# 🎬 Subscriber Churn Prediction

Predicting streaming subscriber churn using engagement, retention, and watch behavior analytics.

---

## Business Problem

Streaming platforms rely heavily on subscriber retention and engagement.

This project analyzes user behavior patterns to identify:
- churn risk
- engagement decline
- retention trends
- subscriber value indicators

The goal is to simulate how streaming companies use analytics to reduce churn and improve customer retention.

---

## Project Goals

- Analyze subscriber engagement behavior
- Identify churn indicators
- Measure retention trends
- Visualize churn risk patterns
- Build executive-style KPI reporting

---

## KPIs Analyzed

- Churn Rate
- Retention Rate
- Watch Minutes
- Subscriber Growth
- Login Frequency
- Device Usage
- Subscription Plan Performance
